让 AI 在动手之前，
先想清楚该用哪把工具。

技能装多了会两难：要么漏用，要么每次任务都刷一屏调度日志。 skill-matcher 把"选技能"做成一个安静的前置步骤—— 能自动就用，有歧义就问，没对口就闭嘴干活。

看安装（30 秒） 在 GitHub 上查看

它解决的两种浪费

01

漏用

明明装了专门处理 PDF 的技能，却手写脚本硬解。

02

噪音

每次任务都汇报"我扫描了 40 个技能，发现 3 个相关……"，用户被迫读调度日志。

装上之后会看到什么

你说它会做
把 report.pdf 按章节拆开一句「用 pdf 处理：…」，然后调用
做个季度复盘，要有图表列出 Word / PPT / 图表三个候选，各带理由，等你选
把这段文字的错别字改一下什么都不说，直接改
把这个 .psd 按图层导出一句「现有技能里没有对口的，我直接做」
你好什么都不说（不触发匹配）

安装（30 秒）

  1. 拿到技能目录

    git clone --depth 1 https://github.com/teenvision/skill-matcher.git /tmp/skill-matcher

  2. 放进技能目录

    把 skill-matcher 目录拷到下面任一位置（没有该目录就新建）：

    # macOS / Linux
~/.workbuddy/skills/skill-matcher/

# Windows
C:\Users\<你>\.workbuddy\skills\skill-matcher\

  3. 验证

    无需重启。对 AI 说一句「用 skill-matcher 处理这个任务」，能加载就说明装好了。

三条设计底线

  1. 产出物优先 —— 先问"要做出来的东西是什么"，再找技能；不看关键词字面重合。
  2. 直调三条件 —— 高相关 且 唯一 且 不改变执行方式，三者缺一不可。
  3. 输出只有三档 —— 确认块 / 一句话 / 零输出。没有第四种。
