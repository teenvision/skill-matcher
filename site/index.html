问题

技能装多了，会同时出现两种浪费

漏用

明明装了专门处理 PDF 的技能，却手写脚本硬解。工具在手边，没人记得用它。

噪音

另一种极端：每次任务都汇报"我扫描了 40 个技能，发现 3 个相关……"，你被迫读调度日志。

skill-matcher 把匹配做成一个安静的前置步骤——只在结论会改变执行方式时才开口。

行为

装上之后会看到什么

你说它会做结局
把 report.pdf 按章节拆开 一句「用 pdf 处理：…」，然后调用 直调
做个季度复盘，要有图表 列出 Word / PPT / 图表三个候选，各带理由，等你选 先确认
把这段文字的错别字改一下 什么都不说，直接改 静默
把这个 .psd 按图层导出 一句「现有技能里没有对口的，我直接做」 未命中
你好 什么都不说（不触发匹配） 静默

安装

三步，约 30 秒

  1. 拿到技能目录

    git clone --depth 1 https://github.com/teenvision/skill-matcher.git /tmp/skill-matcher

  2. 放进技能目录

    把 skill-matcher 目录拷到下面任一位置（目录不存在就新建）：

    # macOS / Linux
~/.workbuddy/skills/skill-matcher/

# Windows
C:\Users\<你>\.workbuddy\skills\skill-matcher\

  3. 验证

    无需重启。对 AI 说一句「用 skill-matcher 处理这个任务」，能加载就说明装好了。

原则

三条设计底线

  • 产出物优先

    先问"要做出来的东西是什么"，再找技能；不看关键词字面重合。

  • 直调三条件

    高相关 且 唯一 且 不改变执行方式——三者缺一不可。

  • 输出只有三档

    确认块 / 一句话 / 零输出。没有第四种。
